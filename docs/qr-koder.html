Under QR-koder i adminmenyn sparar du QR-koder till utskick och affischer: ”bli medlem”, ”anmäl dig till träningen”, ”anmälan till vinterturneringen”. Varje kod har ett namn och en måladress. Du laddar ner koden som bild för tryck, eller visar den på en sida med blocket QR-kod.

Under QR Codes in the admin menu you save QR codes for handouts and posters: “become a member”, “join the training”, “sign up for the winter tournament”. Each code has a name and a target address. You download the code as an image for print, or show it on a page with the QR Code block.

Skapa en QR-kod

Creating a QR code

  1. Gå till QR-koder och klicka på Ny QR-kod.
  2. Go to QR Codes and click New QR code.
  3. Ge gärna koden ett namn som säger vad den är till, t.ex. ”Vinterturnering 2027 – anmälan”. Namnet visas på kortet och blir filnamnet när du laddar ner. Det är valfritt: utan namn används adressen.
  4. Optionally give the code a name that says what it is for, e.g. “Winter tournament 2027 – sign-up”. The name shows on the card and becomes the file name when you download. Without a name, the address is used.
  5. Skriv måladressen: en hel adress (https://…) eller en sökväg på den här sajten, t.ex. /bli-medlem/. En sökväg görs om till en hel adress. Förhandsvisningen uppdateras medan du skriver.
  6. Enter the target address: a full address (https://…) or a path on this site, e.g. /bli-medlem/. A path is turned into a full address. The preview updates as you type.
  7. Klicka på Spara. Koden syns nu som ett kort i listan.
  8. Click Save. The code now shows up as a card in the list.

Klicka på ett kort för att ändra koden. Ta bort (och sedan Bekräfta) tar bort koden för gott. Koden innehåller måladressen direkt, utan omdirigering. Författare ser alla koder men kan bara ändra sina egna; redaktörer och administratörer kan ändra alla.

Click a card to change the code. Delete (then Confirm) removes the code for good. The code contains the target address directly, with no redirect. Authors see every code but can only change their own; editors and administrators can change all of them.

Ladda ner

Downloading

  • SVG — bäst för tryck: bilden blir skarp i alla storlekar.— best for print: the image stays sharp at any size.
  • PNG — för Word, Canva och liknande. I redigeringsfönstret väljer du 512, 1024 eller 2048 pixlar; knappen på kortet ger 1024 pixlar.— for Word, Canva and the like. In the edit window you pick 512, 1024 or 2048 pixels; the button on the card gives 1024 pixels.

Behåll sidans adress

Keep the page's address

En tryckt kod går inte att ändra. Pekar den på en sida, t.ex. /bli-medlem/, ska den sidans adress (slug) ligga kvar. WordPress omdirigerar inte från en gammal adress när du byter slug på en sida, så alla tryckta koder dit slutar fungera. (Inlägg får en omdirigering från den gamla adressen, sidor gör det inte.)

A printed code can't be changed. If it points to a page, e.g. /bli-medlem/, keep that page's address (slug). WordPress does not redirect from the old address when you change the slug of a page, so every printed code pointing there stops working. (Posts get a redirect from their old address; pages don't.)

Vill du byta innehåll: låt adressen vara och ändra sidan, eller ge den nya sidan den gamla adressen.

To change the content: keep the address and edit the page, or give the new page the old address.

Tips: Korten och redigeringsfönstret markerar koder vars adress på den här sajten inte längre finns (Hittades inte (404)). Kontrollen görs som en utloggad besökare, så ett utkast eller en privat sida räknas som saknad. Adresser till andra sajter kontrolleras inte. Tip: The cards and the edit window flag codes whose address on this site no longer exists (Not found (404)). The check is made as a logged-out visitor, so a draft or private page counts as missing. Addresses on other sites aren't checked.

Visa en kod på en sida

Showing a code on a page

Lägg till blocket QR-kod och välj en sparad kod i sidopanelen. Där väljer du också storlek och om namnet eller adressen ska stå under koden. Blocket hämtar adressen från den sparade koden, så ändrar du koden ändras alla sidor som visar den. Tas koden bort visas ingenting för besökarna.

Add the QR Code block and pick a saved code in the sidebar. There you also choose the size and whether the name or the address shows under the code. The block reads the address from the saved code, so changing the code changes every page that shows it. If the code is deleted, visitors see nothing.
