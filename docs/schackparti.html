Blocket Schackparti spelar upp ett parti från PGN — det vanliga textformatet för schackpartier som alla schackprogram och sajter (Lichess, Chess.com, ChessBase) kan exportera. Läsaren stegar genom partiet med pilarna eller tangentbordet, ser kommentarer och varianter, och kan vända brädet eller ladda ner PGN:en.

The Chess Game block replays a game from PGN — the plain-text format every chess program and site (Lichess, Chess.com, ChessBase) can export. Readers step through the game with the arrows or the keyboard, see comments and variations, and can flip the board or download the PGN.

Lägga till ett parti

Adding a game

  1. Lägg till blocket Schackparti (sök på ”schack” eller ”pgn” i blockinfogaren).
  2. Add the Chess Game block (search for “chess” or “pgn” in the inserter).
  3. Klistra in PGN:en i textrutan. Förhandsvisningen uppdateras medan du skriver.
  4. Paste the PGN into the text box. The preview updates as you type.
  5. Välj visning i sidopanelen (se nedan).
  6. Choose the display options in the sidebar (see below).

En PGN kan innehålla flera partier. Då visas en rullgardinslista ovanför brädet där läsaren väljer parti.

A PGN can hold several games. A drop-down above the board then lets readers pick the game.

Tips: Om ett drag inte går att läsa (felstavat eller otillåtet) visar editorn vilket parti och vilket drag det gäller, så att du kan rätta PGN:en innan du publicerar. Tip: If a move can't be read (misspelled or illegal), the editor names the game and the move, so you can fix the PGN before publishing.

Inställningar

Settings

  • Brädets riktningBoard orientation — vit eller svart nederst. Enligt PGN använder PGN-taggen Orientation om den finns, annars vit nederst.— white or black at the bottom. From the PGN uses the PGN's Orientation tag if present, otherwise white at the bottom.
  • DraglistaMove list — till höger om brädet, under brädet eller dold. Automatiskt lägger den bredvid brädet när det finns plats och annars under.— right of the board, below it, or hidden. Automatic puts it beside the board when there is room, otherwise below.
  • StartställningStart position — antal spelade halvdrag när sidan öppnas: 0 är utgångsställningen, 38 är ställningen efter svarts 19:e drag. Enklast är att stega fram i förhandsvisningen och klicka Använd visad ställning. Börja i slutställningen öppnar partiet efter sista draget.— the number of half-moves played when the page opens: 0 is the initial position, 38 the position after Black's 19th move. The easy way is to step through the preview and click Use the position shown. Start at the final position opens the game after the last move.
  • Hitta dragetPuzzle — döljer draglistan och spelarnas namn. Läsaren ser bara ställningen vid startställningen och får själv leta efter fortsättningen, och stega fram för att se lösningen.— hides the move list and the players' names. Readers only see the board at the start position, look for the continuation themselves, and step forward to see the answer.
  • Länkar till LichessLinks to Lichess — lägger till Analys (lichess.org) och Öva (lichess.org) i brädets meny. De skickar partiet till lichess.org först när läsaren klickar. På som standard.— adds Analysis (lichess.org) and Practice (lichess.org) to the board's menu. They send the game to lichess.org only when a reader clicks. On by default.

Menyn för läsaren

The reader's menu

Knappen ⋮ längst till höger under brädet öppnar en meny där läsaren kan vända brädet, visa eller dölja draglistan, öppna partiet på lichess.org för analys eller spel mot datorn, och hämta PGN:en. Inställningarna i blocket bestämmer bara hur partiet visas när sidan öppnas — en läsare som vill se lösningen på en kombination väljer Visa draglistan.

The ⋮ button at the right end under the board opens a menu where readers can flip the board, show or hide the move list, open the game on lichess.org for analysis or to play against the computer, and get the PGN. The block settings only decide how the game looks when the page opens — a reader who wants the answer to a puzzle chooses Show move list.

Äldre inlägg med [pgn]

Older posts with [pgn]

Inlägg skrivna för tillägget Embed Chessboard använder kortkoden [pgn]…[/pgn]. När Embed Chessboard är avaktiverat visar det här tillägget sådana partier med samma visare som blocket — inga inlägg behöver ändras. Inställningarna initialHalfmove, showMoves (inklusive puzzle) och layout följer med; övriga, som height, behövs inte längre och ignoreras.

Posts written for the Embed Chessboard plugin use the [pgn]…[/pgn] shortcode. Once Embed Chessboard is deactivated, this plugin shows those games with the same viewer as the block — no post needs editing. The options initialHalfmove, showMoves (including puzzle) and layout carry over; the rest, such as height, are no longer needed and are ignored.

När du redigerar ett sådant inlägg kan du göra om kortkoden till ett riktigt block: välj Konvertera till block på ett klassiskt block, eller omvandla ett kortkodsblock till Schackparti.

When you edit such a post you can turn the shortcode into a real block: choose Convert to blocks on a Classic block, or transform a Shortcode block into Chess Game.

Obs: Medan Embed Chessboard är aktivt behåller det kortkoden [pgn] och visar partierna som förut. Blocket Schackparti fungerar oavsett. Note: While Embed Chessboard is active it keeps the [pgn] shortcode and shows those games as before. The Chess Game block works either way.
